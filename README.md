# 🏰 The Tale of Pareekshith

> An interactive fantasy-inspired developer portfolio where every skill is represented as a kingdom and every project is part of an adventure.


## 🌐 Live Demo

🔗 https://tale-of-pareekshith.vercel.app/

---

## 📖 About

Instead of creating a traditional portfolio, I wanted to tell a story.

**The Tale of Pareekshith** transforms my software engineering journey into an interactive fantasy world inspired by adventure games and the progression systems found in games like **Clash of Clans**.

Visitors travel through different kingdoms representing my growth as a developer.

- 🏕️ The Beginning
- 🏫 The Academy
- ☕ Java Kingdom
- 🤖 AI Laboratory
- ☁️ Cloud Kingdom
- 🏝️ Projects Island
- 🏰 Resume Castle
- 🔥 The Final Camp

Each section represents a milestone in my learning journey.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/the-tale-of-pareekshith.git
```

Go into the project

```bash
cd the-tale-of-pareekshith
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build production version

```bash
npm run build
```

# 🎯 Inspiration

This project was inspired by the sense of progression, exploration, and achievement found in fantasy games such as **Clash of Clans** and anime **One Piece**.

Rather than listing skills on a single page, every technology is represented as a kingdom, turning my learning journey into an interactive experience.
